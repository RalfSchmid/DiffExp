## Files for practising intersections
This repository contains two files from publicly available data used for training in a beginners Bioinformatics programming session.
###
The first file is a gene list from an RNAseq experiment published in "Translatome analysis reveals altered serine and glycine metabolism in T-cell acute lymphoblastic leukemia cells" https://pubmed.ncbi.nlm.nih.gov/31186416/. The actual datafile was downloaded from [refinebioexamples](https://refinebio-examples.s3.us-east-2.amazonaws.com/03-rnaseq/results/SRP123625/SRP123625_differential_expression_results.tsv). The version in this repository has been cleaned to avoid 'empty field' errors.
###
The second file is a 'trimmed for easier processing' version of a mouse genes GO-annotation file downloaded from [MGI](https://www.informatics.jax.org/downloads/reports/index.html).
